# 那什么的文游编辑器

> 一个开箱即用的**本地文字游戏编辑器 + 播放器**。零依赖、零安装、纯前端单文件，双击就能写、就能玩、就能导出。

## 这是什么

用**卡片 + 连线**的方式写文字游戏：剧情、选项、检定、数值、任务、结局、跳转、随机、插图、战斗，一共 10 种卡片。
写完点「▶ 试玩」立刻能玩，满意后「导出游戏」生成**一个可以单独发给别人的 HTML**（双击即玩，不依赖编辑器）。

- **完全离线**：不联网、不装环境，浏览器打开即可
- **单文件应用**：`那什么的文游编辑器.html`（`index.html` 内容相同，供 GitHub Pages 使用）
- **工程可带走**：导出 `story.json`，换电脑/换人继续编辑
- **成品可分发**：导出的 `.game.html` 自带引擎，对方双击就玩
- **适合同好**：无账号、无后端、无遥测

## 快速开始

1. 下载本仓库（或直接下载 `那什么的文游编辑器.html`）。
2. **双击 `那什么的文游编辑器.html`**（名字最直白的那个；`index.html` 是同一份内容）。
3. 想直接看成品：双击 `demo/新手教程.game.html`（约 5 分钟，走完全部 12 种卡片）。
4. 第一次用？点右上角 `?` 看帮助，或「全局 → 载入新手教程」，里面有每种卡片和一次战斗演示。
5. 用不到的系统？「设置 → 功能开关」可以逐项关掉（立绘/角色卡/背包/装备/任务/图鉴/地图/时间/角色创建）。
6. 界面太小？编辑器顶栏的百分比下拉、游玩页右上角「Aa」，75%–150% 随时调。
7. 换风格？游戏内 UI 在「设置 → 游玩页界面」点卡片（10 套内置，还能导入自定义主题）；编辑器自己的外观在顶栏「编辑外观」下拉，互不影响。

> 打开后默认载入新手教程；你的修改会自动保存在浏览器本地（右上角有保存状态）。
> 换电脑或清理浏览器缓存前，请用「导出工程」备份。

## 1.1 新增了什么

| 功能 | 说明 |
|---|---|
| **NPC 角色卡** | 立绘页给 NPC 填身份、简介、自定义字段，再传一张**全身立绘**；玩家点对话头像就能看到这张卡。可整体关闭（关了点头像没反应）。 |
| **演出（舞台）模式** | 按卡片开启：整幅背景 + 站位立绘（位置可滑杆微调、说话人自动前置、其他人压暗退后、主角固定右半边）+ **不再画对话框**，台词直接浮在画面上（旁白无头像，对话才带头像与名字牌）。正文**自动分页**，点画面任意处翻页。背景放"背景库"复用，不重复占体积。 |
| **富文本** | 选中文字就能加**颜色 / 荧光笔高亮 / 四档字号**；预设跟着游玩页主题变（鎏金给金朱、水墨给朱砂石青……）。也支持 `[c=#ff6600]…[/c]` 手写标记。 |
| **自定义主题** | 设置页可导入主题包 JSON（AI 写也行）：内置「格式说明」+「复制 AI 提示词」+ 示例包。导入后立刻能用，也会跟着「导出游戏」一起发出去。 |
| **CG 演出** | 导了图的插图卡用和演出背景**同一套整屏版面**（默认 `cover` 铺满，也可选 `contain` 完整显示留黑边），加题注 + 右上「看大图」+ 下方文字层分页。 |
| **面板瘦身** | 效果/条件/选项/反馈文字默认折叠（标题行带条数摘要），角色卡编辑搬进弹窗，立绘页一屏放得下。 |
| **工程体积** | 状态栏显示工程大小；超过 3.4MB 自动改存浏览器数据库（IndexedDB），长线工程不容易再撞 5MB 上限。 |
| **立绘差分** | 一个 NPC 可以配多套立绘（表情/姿态），台词写 `【林晚2】` 就用 2 号；没配 2 号会往前退到 1 号，一个都没配就用基础立绘。 |
| **打字音效** | 七种预设（静音/打字机/轻敲/电子音/木鱼/铃/自定义音频），可试听、调音量、导入音频；能套到全部卡片/当前章节并撤回，单卡也能覆盖。 |
| **回合制战斗** | 四个按钮：攻击 / 技能 / 道具 / 防御。技能可设威力、消耗、回血与台词；物品可设回复/伤害效果；敌人能配立绘，战斗也能用演出版面（敌人站正中）。战斗面板**跟着主题走**（`--bt-*` 一组变量可单独调色），不再是外挂的一块深色框。 |
| **工程上限** | 设置页直接列出「能装多少东西」：当前体积、卡片数，以及实测参考和安全区间（800–1500 张卡、40–80 张背景）。 |
| **手势防护** | 长按拖卡片/连线不再拉起浏览器原生拖拽、不再选中文字、右键不弹菜单、`Ctrl+D/S` 之类的快捷键不再误触。 |
| **一句一页** | 演出版面里旁白可以几段一页，但**每句对话都独占一页** —— 点一下出现下一句，上一句消失，跟家用机 RPG 一样。 |
| **`{player}` 变量** | 正文、对话、选项、角色卡里写 `{player}`，游戏里自动换成角色创建时起的名字（没起名就显示「你」）。 |
| **画布多选** | `Shift` 拖空白框选多张卡片，选中的可以**一起拖动**，也能一键「用这些卡片建章节」；`Delete` 一次删掉全部选中。 |
| **存档提醒** | 新增卡片数（默认 25 张）或连续编辑时长（默认 40 分钟）到点后，画布顶部浮出「导出工程备份」提醒条；阈值可改、可关闭，提醒时还能响一声（7 种系统风格提示音，可静音）。 |
| **内置教程重写** | 只留《A氏的新手教程》：14 张卡片把 12 种卡片全走一遍，主角 A氏 是颜文字团子（4 个差分），书房背景与插图都用矢量图，默认蜡笔涂鸦风 + 打字机音效。 |
| **头像取景** | 每个 NPC 的对话头像可以自己卡：框形状（圆 / 方 / 竖长）、缩放、横向、纵向四个参数，立绘页左边就是实时预览，圆框不再硬套方图。 |
| **立绘纵向 / 大小** | 出场立绘除了左右位置，还能上下调、能整体缩放，脸被画面挡住或头露不出来时直接拖滑杆。 |
| **演出默认关** | 只有需要整幅画面的卡片才开演出（教程里只有第一张剧情和战斗开着），其余卡片走普通对话框版面，不再默认铺背景。 |

## 开发

源码不是启动 HTML，而是 `css/style.css` + `js/*.js` + `index.template.html`。改完运行：

```bash
node build.js
```

会生成 `那什么的文游编辑器.html`、`index.html` 和自检页 `test.html`。
`build.js` 会把 CSS/JS 内联进单文件应用（导出游戏功能依赖内联源码）。

自检（无头 Chrome / Edge，360 项，含内置教程完整通关）：

```bash
chrome --headless=new --disable-gpu --user-data-dir=/tmp/nt \
  --virtual-time-budget=240000 --dump-dom "file:///<绝对路径>/test.html"
```

命令行导出游戏（不打开浏览器）：

```bash
node tools/export-game.js --story demo/新手教程.json --out 我的游戏.html
```

## 导出与分发

- **导出工程**：得到 `story.json`，可再次导入继续编辑。
- **导出游戏**：得到单个 `.game.html`，内含引擎、故事和图片，对方双击即玩；
  顶栏的任务/角色/背包/地图/图鉴/存档全部可用。

## 挂到线上给人试玩

`deploy/` 里是打包好的线上版，三个文件、不到 1MB，整个目录传上去就能用：

| 文件 | 内容 |
|---|---|
| `index.html` | 入口页（「直接玩教程」/「打开编辑器」两扇门） |
| `editor.html` | 编辑器本体 |
| `play.html` | 内置教程导出的成品游戏 |

重新生成（改完代码或教程后跑一次）：

```bash
node build.js && node tools/export-game.js && node tools/make-deploy.js
```

托管方式任选一种，都是把 `deploy/` 整个传上去：

1. **Netlify Drop** —— 打开 `app.netlify.com/drop`，把 `deploy/` 拖进网页，几秒后拿到 `xxx.netlify.app`；
   免注册能先用，想固定域名再登录。
2. **GitHub Pages** —— 新建仓库，把 `deploy/` 里的三个文件推到仓库根目录（或推到 `docs/`，
   再到 Settings → Pages 里把来源选成 `docs/`），一两分钟后访问 `用户名.github.io/仓库名`。
3. **Cloudflare Pages / Vercel** —— 连仓库或直接上传目录，构建命令留空，输出目录填 `deploy`。
4. **国内对象存储** —— 阿里云 OSS / 腾讯云 COS 开「静态网站托管」，传三个文件，入口文件填 `index.html`；
   绑自定义域名需要备案。

两点注意：编辑器是纯前端，**每个人的工程只存在他自己的浏览器里**（localStorage / IndexedDB），
换设备要用「导出工程」带走；你更新版本后重跑一次打包再传，别人刷新就是新版。

## 兼容性与注意

- 推荐 Chrome / Edge / Firefox 近两年的版本（用到了 CSS `:is()`、可选链等现代特性）。
- 数据保存在浏览器 `localStorage`（约 5MB）：立绘、CG 多的时候注意体积，右上角会提示保存失败。
- 换电脑、换浏览器或清理缓存前，请先「导出工程」备份。
- 导出的游戏是纯静态 HTML，玩家存档同样保存在玩家自己的浏览器里。

本编辑器由 AI 辅助完成，完全支持改版制作：

- 启动 HTML 里的 CSS / JS 都是**未压缩**的，搜索 `NT_NODE_TYPES`、`Game`、`Inspector` 等关键字即可定位；
- 建议先读 [交接文档.md](交接文档.md)，里面有数据模型、模块职责、路径约定、构建与测试方法、每个设计取舍；
- **如果使用 AI 制作改版，请让 Agent 先阅读 `交接文档.md`**，再动手。
